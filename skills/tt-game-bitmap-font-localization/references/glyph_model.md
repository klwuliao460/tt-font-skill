# 字形三层模型 + 度量对齐协议

> 校准目标取自 LMSH2 原版 `FONT_CH_NXG.FT2.bak` 实测。**换游戏/换字体时必须先用
> `scripts/font_probe.py` 重新量原版**，把量到的 `core_h / core_bot` 传给 `font_generate.py`，
> 不要沿用别处的数字。

## 1. 原版字形 = 三层结构

| 层 | RGB | alpha | 作用 |
|---|---|---|---|
| 白色核心 | 255,255,255 | 高（边缘 AA 渐变） | 看得见的笔画 |
| 描边环（1px） | ≈0,0,0 | **255** | 贴在任何背景上都能读 |
| 宽软光晕 halo | 深色 | 20–128 | 柔化边缘 |

- 交接文档常说的"图集 RGB 全白、只有 alpha 有意义"是**错的**（见 dead_ends.md）
- halo **不可复刻**：27px 的密字字腔只有 3px，加 halo 会把字腔填黑
- 复刻目标只做前两层：白色核心 + 1px 近黑描边环

## 2. 度量协议（`font_probe.py` 输出字段）

| 字段 | 定义 | 判据 |
|---|---|---|
| `core_h` | 白色核心紧致墨迹高 | **校准基准** |
| `core_w` | 白色核心紧致墨迹宽 | 与 rect.w 比，超了要缩 |
| `alpha_h` | 核心+描边（alpha>128）墨迹高 | = core_h + 2 |
| `alpha_w` | 同上宽 | |
| `core_bot` | 核心墨底相对 `rect_y` | 基线对齐用 |
| `alpha_bot` | alpha 墨底相对 `rect_y` | = core_bot + 1 |
| `ring_above / ring_below` | 核心上/下描边环厚 | 目标 1 / 1 |
| 核心水平游程众数 | 核心掩膜内水平游程（≤20px）众数 | 竖笔粗细 |

**阈值定义（2026-11-05 用 `font_probe.py` 复核，别再改）**

- 墨迹 `alpha > 128`（排除 alpha 20–128 的软光晕）
- 白色核心 `alpha>128 且 min(R,G,B) > 128`
- ⚠ 用 `min(RGB) > 200` 判核心会**因 BC1 量化把核心最底行算成描边**，实测核心少 1px（26/38 而非 27/39）

## 3. 实测目标值（LMSH2 原版，1200 字样本）

```
core_h   中位/众数 = 27     alpha_h  中位/众数 = 29
core_bot 众数 = 39          alpha_bot 众数 = 40
ring_above/below = 1 / 1    竖笔游程众数 = 2px（中位 3px）
alpha_max 众数 = 255
```

- **校准基准 = 核心墨高 27**，不是 alpha 墨高 29（后者含 1px 描边，会大 2–3px）
- 渲染源：`C:\Windows\Fonts\NotoSansSC-VF.ttf` **可变字体**，`set_variation_by_axes([500])`
  - weight 探针实测：**500** → 竖笔众数 2 / 中位 3，与原版同；**875 / 700 过粗**
- 渲染流程：`E_BIG=192` 大字号渲染 → 中位墨高 179 → `scale = 27/179 = 0.1508` → LANCZOS 缩小

## 4. 四个必踩坑与修法（`font_generate.py` 已实现）

1. **LANCZOS 缩小在笔画内产生振铃零值行** → 核心掩膜必须用 `a2 > 90` 实心掩膜 **+ 填洞**
   （`fill_holes`：只填包围盒最小边 ≤2px 的细缝；填全部洞会把 图/囗/日 的字腔填成豆腐块）
2. **描边环封死窄字腔** → `reopen_tiny_counters`：把连通域 ≤3px 的封闭空白邻接描边去掉重新打开；
   大字腔保留描边
3. **清理区必须覆盖自身 rect**（只保护邻格会夹空 → 原字残影）；且清理块必须进 BC3 重编码集合
   （漏了 = 残影）。清理 x 范围由 `clear_bounds` 按同行邻居钳制
4. **贴图只写 `comp_a > 0` 的像素**，非字形像素 RGB 写 0（写 255 会在图集里留脏数据）

## 5. BC3 重编码纪律

- **只重编码被触碰的 4×4 块**（清理区 + 贴图区的并集），其余字节原样
- 表区（头 + 坐标表 + 字符表）一个字节都不许动 —— 生成后按字节比对输入
- 编码器：`bc3_encode_batch`，全向量化，约 14 万块 7 秒；LMSH2 全量替换 1074 槽 ≈ 14.3 万块

## 6. 验证清单（每轮生成后、部署前）

- [ ] 输出长度 == 输入长度，表区字节完全一致（`font_generate.py` 自动查）
- [ ] 字符表 cp 升序、gi 集合未变（`font_probe.py` 结构段）
- [ ] 未触碰块像素差异 = 0
- [ ] 抽样旧字（非替换槽）度量不变 —— 变了 = 清理区夹到邻格
- [ ] 新字 `core_h` 众数 == 目标 ±1、`core_bot` == 目标、描边环 == 1/1
- [ ] 混排预览图目检（`--preview`：新字与旧字并排 x6 放大）
- [ ] 进游戏截图 —— **唯一真值**；度量与截图冲突时以截图为准重新测量
