# 已证伪路线清单（禁止重试）

> 每条都带实测日期与现象。**在这些方向上再花时间 = 重复踩坑**；要推翻必须有新的游戏内截图证据。
> 来源：2026-10-31《乐高漫威超级英雄2》简中字体实战（本地工件目录：生成器/脚本/报告/成品字体
> 全在一个 `lmsh2_font/` 工作区目录里，仓库里不含这些游戏文件）。

## 1. 插入 / 追加字符表或坐标表记录、加高图集、改计数

- **日期**：2026-10-31（`make_surgery_test.py` → `FONT_surgery_test.FT2`）
- **现象**：改完自己用解析代码读回**完全自洽**（升序、gi 有效、图集能解码），进游戏**"字没了"**
- **根因**：exe 里**硬编码了表偏移/表长**，不按文件里的计数字段走
- **结论**：只做原地等长修改（见 ft2_format.md §7）

## 2. 文本里使用私用区 / 生僻码位（半号拉丁槽位路线）

- **日期**：2026-10-31（`make_caps_font.py` + `caps_map.json` → `FONT_CH_NXG.FT2.caps_ff61.bak`）
- **做法**：原地回收 32 个部署文本用不到的槽，画半号大写拉丁，文本用 `U+FF61` 段码位承载
- **现象**：**启动期闪退**，即使字体里确有该字形、字符表仍升序
- **补充**：`U+9FE0` 段 CJK 尾同样闪退；新码位还必须 > 表内最大 cp 才能保持升序
- **结论**：**新槽位 / 小号英文路线整体不可用**，成品字体已回滚到 weight500 基线
  （部署版 md5 `3cab92576377b344e6ccb0040567fd8d`）

## 3. 字幕用 `\n` 求"中英同时双行显示"

- **日期**：2026-10-31（`TEXT.CSV.seq.bak` / `.seq2.bak` 轮播版）
- **现象**：字幕元素是**单行分页**——`\n` 只让两行轮流出现，不是同时；没有电影感
- **补充**：面板类文本（`TYPE=Game/Char/Hint`）才支持多行同时，两者渲染器不同
- **结论**：要"同时可见"只能靠**同行拼接 + 宽度预算分流**

## 4. 半号 / 小号英文字幕

- **日期**：2026-10-31
- **结论**：#1（不能加槽）+ #2（私用码位闪退）叠加后**无解**；
  现存唯一形态是全尺寸英文 + 预算分流（csv_workflow.md §4）

## 5. 交接文档"HANDOVER.md §9：图集 RGB 全白、只有 alpha 有意义"

- **日期**：2026-10-31 实测推翻，2026-11-05 用 `font_probe.py` 复核
- **现象**：按"全白"渲染出的字**粗细不均 / 发糊**，与原版并排一看就不对
- **真相**：原版是**三层** —— 白色核心（`min(RGB)>128` 且 `alpha>128`，墨高中位 27）
  + 1px 近黑描边环（RGB≈0、alpha 255）+ 宽软深色光晕（alpha 20–128）
- **附带坑**：判核心用 `min(RGB)>200` 会因 BC1 量化把核心最底行算进描边，核心少 1px（26/38）

## 6. 按图集阅读序推字形位置（旧脚本 k-1 / k-3 映射）

- **日期**：2026-10-31（`walk_align.py` / `probe_order.py` 阶段）
- **现象**：按图集 blob 顺序映射码位，抽样能对上、全量就错位（1165/1167 处需要补丁偏移）
- **真相**：**坐标表 `0x4F + 28*(gi-1)` 才是权威**；图集里的视觉顺序不可靠

## 7. 靠"重开一次游戏"解释异常

- **日期**：2026-10-31
- **现象**：LMSH2 本身有**间歇性启动/渲染问题**，第一轮异常可能不是改动引起的
- **结论**：闪退先**单变量隔离 + 重开一次**排除既有问题，再决定回滚（见 SKILL.md 纪律）
